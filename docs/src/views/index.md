# Vgo UI

实用型 Vue 3 组件库，[快速上手](docs/install)

## Features

- 自用：用于个人项目和学习使用，不建议用于生产环境
- 极简思路：用 CSS 变量和类丰富原生 HTML 样式 [样式总览](/docs/styles)
- 实用主义 Auto 组件：基于 Element Plus 实现了 [AutoTableElPlus](/docs/table)、[AutoFormElPlus](/docs/form)、[OptionUI](/docs/option-ui) 等组件，传参即UI

## 这个库不做的事

- 不做 Element Plus 已有的功能，不重复造轮子

## 技术栈 / Tech Stack

- TypeScript
- Sass(scss)
- [Vue 3](https://vuejs.org/guide/quick-start.html) / [VueUse](https://vueuse.org/functions.html)
- [Element Plus](https://element-plus.org/zh-CN/component/overview)
